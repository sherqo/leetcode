# Adding Solutions

This repository stores one LeetCode solution per file, grouped by topic.

1. Find the problem in `README.md` and identify its topic section.
2. Use the exact LeetCode URL slug as the filename in that topic directory, for example `arrays-and-hashing/two-sum.go`.
3. Keep the solution function named as required by LeetCode.
4. Mark the problem `[x]` in `README.md` only after adding the solution.
5. Keep unrelated files and formatting unchanged.
6. Preserve each solution exactly as provided. Do not optimize, refactor, translate, or otherwise change the implementation. Formatting-only changes, such as spacing or indentation, are allowed.

Solutions may use different languages. Keep the language extension with the exact slug, such as `two-sum.go` or `valid-sudoku.cpp`. If a new topic directory is needed, create it using the same naming style as the README heading.
